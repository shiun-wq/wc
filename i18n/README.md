# 多語言（i18n）

哇娃衣櫃的原文是繁體中文。這個資料夾讓畫面也能顯示簡體中文和英文。

- `i18n.js`：選語言（設定 → 語言；預設跟隨手機），把畫面上的字換成對應的語言。
  只換「顯示的字」，存起來的資料（類別、狀態、名字…）一律維持原本的繁體中文，切換語言不會動到資料。
- `en.js`：英文字典 `{原文: 譯文}`，原文裡的 `{0}` `{1}` 是變數。
- `hans.js`：簡體中文字典，另外附一份單字對照（使用者自己打的字也會顯示成簡體）。

改了字典之後，記得把 `index.html` 裡 `i18n/i18n.js?v=` 和 `i18n.js` 裡的 `V` 一起加 1，手機才會拿到新版。
