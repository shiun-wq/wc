# 哇娃衣櫃 交接手冊

更新：2026-09-29（版本 2026.10.01-35 之後）

---

## 1. 這是什麼
娃衣（棉花娃、OB11 等）的衣櫃 App。使用者拍照建檔、做成貼圖、搭配、記錄每天的穿搭和出門足跡，還有娃娃的紀念日、星星罐、年度回顧等等。

- 網址：https://shiun-wq.github.io/wc/ （GitHub Pages，`main` 分支就是正式版）
- 形式：PWA（可以加到主畫面），正在準備包成 App（Capacitor）
- 語言：繁體中文為主，另有簡體中文、英文（預設跟隨手機）

## 3. 資料怎麼存
- 全部存在使用者的手機（IndexedDB）。**沒有雲端**，換手機要靠備份檔。
- 主要資料都在全域物件 `S`：`S.items`（娃衣）、`S.sets`（套裝）、`S.looks`、`S.wears`（穿搭紀錄）、`S.dolls`、`S.wish`（考慮中）、`S.orders`（購買中）、`S.memory`（回憶箱）、`S.settings`。
- 照片欄位（`IMG_FIELDS`）另外存，`save()` 會自動處理。
- 備份：`exportBackup()` 用 `backupParts()` 一段一段組成檔案（**不要改回整份 JSON.stringify**，照片多時 iPhone 會記憶體不足、整頁當掉）。還原是 `importBackup()`。

### 重要的資料欄位
- 單品頁 `setPiecesBlock(i)`：套裝頁列出「這套有 N 件」，單品頁列出「同一套還有 N 件」，都可以點；「所屬套裝」可以點回套裝。
- 單品頁「📷 換照片」`rephoto(id)`：已建檔的娃衣重拍，換掉 `i.photo`、清掉貼圖後接著 `recut`；名稱、價格、穿搭紀錄都保留。
- 建檔省力（2026-09-30）：色票 `swatchHTML()`／`toggleColor()`（12 色系＋花色，存「粉色」這種名字，最多 3 個）在編輯頁、批次修改（建檔清單是一顆「🎨 顏色」按鈕 `qColorOpen()`）；顯示名稱用 `nameOf(i)`：同名的自動加顏色「名稱・粉」；批次可以改名稱、購買管道；建檔清單「📋 套用到全部」`applyQueueAll()`（尺寸全換，其他只填空白，價格可總價平分 `splitPrice()`）；名稱留白自動取「顏色＋類型」並標 `autoName`；衣櫃「可以補充」（篩選最後面，不給壓力）`missingInfo()`（缺顏色、價格、日期、自動名稱）；批次改價格可總價平分，套裝的單品跟著套裝價格。
- 統計的共同規則（2026-09-30 整理）：價格用 `priceOf(i)`（套裝拆出來的單品都複製了套裝價格，一套只認「套裝」那筆）；「穿搭」用 `outfitWears()`（陪伴日常沒選衣服也沒照片的不算換裝，但娃娃出場、陪伴統計照算）；以套為單位用 `wearGroups(w)`（整套都穿到或勾了套裝才算整套，只穿一部分就算那幾件）＋`grpWearCount()`；花費的「用到一套」用 `setUseCount()`（穿到任何一件就算用到）；被冷落、飽和、可以整理都用 `isPressed()`（跟壓箱底同規則）。花費包含回憶箱裡的（錢已經花了）。
- 搭配分析 `matchStats()`：同一套的單品合成一組（`gk()`），跟套裝一起穿只算搭了一套；最萬搭、總是一起出場都以組為單位，套裝顯示成「套裝」那筆。
- 穿搭小記事 `w.note`（選填，最多 300 字）：記穿搭底部固定列的 ✏️ 展開 `wearNoteBox()`；紀錄詳細、月曆那天會顯示；做小卡時帶進一句話 `noteCap()`（前 60 字），這筆沒寫過的話小卡的一句話會存回小記事（有寫過的不會被蓋掉）。
- 穿過幾次 `wearCount(id)`／最近 `lastWear(id)` 都用 `wornIn()`：直接勾了它，或它是套裝、而那筆把套裝裡的單品全部都勾了。
- 娃衣 `i`：`series`（系列，選填，在品牌上面；套裝改了會同步到單品）、`brand`、`shop`、`origin`。
- 娃娃 `d`：`home`（到家日）、`dates`（使用者加的紀念日 `{id,label,md,year}`）、`stars`（星星罐）、`away`（暫時離家）、`archived`、`gone`、`keepsake`、`styles`（適合的風格）、`outs`／`outPlaces`（出門）。
- 穿搭紀錄 `w`：`place` 是 `在家`（或空白）、`出門`、`上班`。`上班` 是「陪伴日常」（`rid` 記是哪一個日常，舊紀錄沒有 rid 算第一個；日常存在 `S.settings.routines`，最多 3 個，每個有 `label/mode/days/shift/ask`，舊的 `workLabel` 等設定會自動搬進第一個）：衣服可以不選（`itemIds` 空的），**不算出門、不進足跡**，但算有換裝（好久沒換裝不會提醒）。每個 helper 都吃一個日常 `r`（不給就是第一個）：畫面上的名字 `workLbl(r)`（`WORK_KINDS`：上班、上學、上課、讀書、補習、打工、實習、去工作室、通勤，也能自己取），圖示 `workIcon()`、分析裡的稱呼 `workMate()`（最佳同事／同學／讀書夥伴…）；設定在「設定 → 陪上班」。上班日：固定星期 `workDays()` 或排班 `workMode='shift'`＋`workShiftDays`（一天一天點，月底沒排下個月首頁會提醒 `shiftCard()`），判斷用 `isWorkDay()`；年度回顧 `yearStats().work` 有「年度最佳同事」，加班 `isOT(w)`：這個日常有排上班日、但那天不是 → 加班（`workExtra()`：上班→加班、上學上課補習→補課、讀書→假日讀書），記錄時跳 `openOtCheer()` 鼓勵，按「謝謝」後 `otThanks()` 問要不要寫星星紙條（預填「謝謝你今天陪我加班」），履歷、會員分析「加班夥伴」、年度回顧都有；首頁卡片有「今天放假 🌴」。首頁一鍵記錄 `workCard()`（今天記過在家／出門也照樣問，只看這個日常今天記了沒），娃娃履歷「工作紀錄」，會員分析 `workSection()`「誰最常陪你上班」。
- 娃娃履歷的月曆 `dollCal(d)`（在「整理紀錄」上面）：一天一個圖示 `dayIcon()`，優先順序 🎂 紀念日 > 🚶 出門 > 🌙 加班 > 日常圖示 > 🏠 在家；好幾筆有小點；點日期在下面展開 `dayRecs()`，只重畫月曆 `dcalDraw()`。一週從哪天開始 `S.settings.weekStart`（0 日／1 一，預設一，設定 → 外觀），排班月曆也用。
- 星星 `{id,text,date,open,at,opened,openedAt}`：`open` 是 `anniv`（到家紀念日）、`d:<紀念日id>`、`date`（指定日）、`now`。
- 購買中 `o`：`series`（系列，選填）、`brand`、`shop`、`stage`、`photo`、`photoSrc`（截圖匯入多留一圈的原圖）、`photoCrop`、`colors/styles/motifs`（截圖匯入讀的）。

## 4. 功能地圖
- **首頁**：跟著主角娃娃。提醒卡（紀念日、好久沒換裝、星星罐、年度回顧、換季…）都在 `homeCards()`。每日推薦 `todayPick()`＋`outfitScore()`（顏色、風格規則）。
- **衣櫃**：`renderCloset()`、批次修改、壓箱底、出售貼文、回憶箱。
- **建檔**：拍照 → 選尺寸 → AI 分析（選用）→ 貼圖（點選去背、筆刷、AI 出圖）。
- **搭配**：畫布、Look、「幫我搭一套」（隨機 `ideaRandom()`／AI）。
- **娃娃櫃**：三個分頁「🧸 娃娃／📍 足跡／⭐ 星星罐」；娃娃頁 `drawDollPage()`（履歷）、`drawDollEdit()`。
- **洞察**：一般分析、會員分析兩個分頁（`UI.insTab`），會員分析有：娃娃的一年、搭配、套裝排行、每隻娃娃、季節節日配色、穿搭習慣、花費。
- **購買中**：單筆、一次記多筆、批次修改、📸 截圖匯入（會員，AI 讀訂單截圖，外幣換算 `fxRate()`）、✂️ 調整商品圖（`openCrop()`）。
- **分享小卡**：`openShare()`／`scDraw()`；種類：穿搭、Look、紀念、足跡、年度回顧；會員配色（薄荷、薰衣草、奶茶、晴空）和邊框（`scFrame()`）。
- **設定**：會員與 AI、提醒與通知、我住在（國家＋記帳幣別）、外觀、語言、衣櫃類別、娃衣尺寸、貼圖製作、備份與資料、開發者模式（點「設定」標題 7 下）。

## 5. 會員、試用、價格
- `isMember()` = 已開啟會員 或 試用中（`trialOn()`）。
- AI 額度在 `QUOTA`：每月 1 號重置；有 `free`、`member`、`trial` 三種次數；用完可以用點數（`POINT_COST`）。
- 免費試用 3 天（`TRIAL_DAYS`），每人一次；試用時分析全開、AI 次數較少。
- 價格 `PLANS`／`PACKS`：台灣 NT$90／月、NT$900／年；其他國家 US$3／US$30；點數包國外 US$0.99／2.99／5.99。顯示用 `priceText()`。
- **目前付款、恢復購買、管理訂閱都是佔位按鈕**；設定裡有「測試用：直接開啟會員」，上架前要拿掉。
- 「我的會員」頁：`openMemberHub()`（右上角「♛ 會員」）。

## 6. 多語言
- 只換「畫面上的字」，**存的資料一律是繁體中文**。程式要讀按鈕上的原文時用 `txt(el)`（畫面翻譯時會把原文記在 `data-o`）。
- 字典是 `{繁中原文: 譯文}`，原文裡 `{0}{1}` 是變數。
- **新增或修改中文字之後，補英文的方法：**
  1. 把 `"中文原文": "English"` 加進 `tools/i18n/extra_en.json`（這裡的會蓋過舊翻譯）
  2. `node tools/i18n/build_en.js` → 產生 `i18n/en.js`
  3. 測一句：`printf '穿搭紀錄\n' | node tools/i18n/trtest.js`（簡體：`node tools/i18n/trtest.js zh-Hans`）
  4. 把 `i18n/i18n.js` 的 `V` 和 `index.html` 的 `?v=` 加 1
- 簡體字典用 OpenCC 產生（`tools/i18n/build_hans.js`，需要 `npm i opencc-js`）；沒收錄的字會用逐字對照自動轉，通常不用重跑。
- `tools/i18n/extract.js`（需要 `acorn`、`acorn-walk`）可以重新抓出全部中文字串到 `strings.json`；`en_0～7.tsv` 是第一批人工翻譯。
- 注意：canvas 上畫的字也會被翻譯（`fillText` 被包起來），所以小卡的單位文字長度要用 `measureText` 量，不要寫死位置。

## 7. 說明頁
- 內容在 `HELP`（主題、步驟、小提示）、`HELP_CATS`（分類：衣櫃、穿搭、娃娃、購物、會員、資料）、`HELP_SHOTS`（每個主題用哪幾張截圖）。
- 截圖用 `tools/shots/shots.js` 產生（Playwright、示範資料、假日期 2026-12-24、390×700）。**它需要 `dolls.json`（示範娃娃照）和 `trip/*.jpg`（示範旅行照）放在 `tools/shots/`，這些是使用者的照片，所以沒有放進 repo**，需要時請使用者提供。
- 用法：先把網站放在 `http://localhost:8772/`，再 `ONLY=star-jar,jar-list node tools/shots/shots.js` 只重拍指定的圖。
- 沒有使用者照片時，**不會拍到娃娃的圖**（例如 `orders`）可以把 `shots.js`、`clothes.js` 複製到暫存資料夾，放一個假的 `dolls.json`（四個 1×1 圖）和 `trip/*.jpg`，把 `OUT` 指回 repo 的 `help/`，用 `ONLY=` 只拍那張。**拍完一定要 `git status help/` 檢查，只留下要重拍的那張**，拍到娃娃的圖不能用假照片。
- 新增主題時要確認每張 `HELP_SHOTS` 的圖都存在、`help/` 裡沒有用不到的圖。

## 8. 後台（Cloudflare Worker）
- `server/worker.js`，網址寫在 `index.html` 的 `BACKEND`。
- 功能：轉接 AI（任務 `tag`、`buy`、`wearid`、`idea`、`img`、`test`），密鑰只存在 Cloudflare 的設定裡。
- `ALLOWED_ORIGINS`：允許使用的網址。**包成 App 之後要加上 `capacitor://localhost`（iPhone）和 `https://localhost`（Android）**，由使用者自己去 Cloudflare 改。
- 匯率：`https://open.er-api.com`（免費、不用密鑰，一天抓一次）。

## 9. 怎麼測試
- 用 Playwright（全域安裝），Chromium 在 `/opt/pw-browsers`。
- 起一個本機網站：把 `index.html`、`version.json`、`i18n/`、`maps/`、`help/`、`icons/` 複製到一個資料夾，`python3 -m http.server 8772`。
- **瀏覽器語系一定要設 `locale:'zh-TW'`**，不然會照「跟隨手機」切成英文，點中文按鈕的測試會找不到東西。
- 語法檢查：把 `<script>` 內容丟給 `new Function()` 跑一次。
- 以前的測試腳本都在舊對話的暫存資料夾，已經不在了；需要時照這個方法重寫就好。

## 10. 使用者做過的決定（不要改回去）
- 回血只算娃衣。
- 年訂 NT$900；國外用美金 US$3／US$30。
- 試用 3 天；試用時 AI 次數：建檔 20、買前 5、出圖 5、辨識 10、搭配 10。
- 首頁右上角「♛ 會員」→ 我的會員；錢包在頁面最下面。
- 說明頁圖片先只做繁中；語言只做繁中、簡中、英文（日文、韓文之後再說）。
- 雲端備份：先做 A 方案（存到使用者自己的 iCloud／Google 雲端硬碟，自動、不用登入），等上架成 App 時做；B 方案（自己的後台同步）看會員數再說。現在只有手動備份＋教學。
- 截圖匯入放在購買中，不放建檔頁（截圖的小圖太小，做貼圖會糊）。到貨拿去建檔時，建檔清單會提醒換實物照（`q.fromOrder`，`qPhoto(n)` 換照片，貼圖重做、其他資料保留）。
- 星星罐：打開日期列出到家紀念日＋使用者加的每個紀念日，最後才是指定日期；首頁提醒放在「好久沒換裝」下面；娃娃頁用一行入口，不要大卡片。

## 11. 進行中：包成 App（使用者選的第 1 項）
**已做（已合併進 main）**：
- `isApp()`：判斷是不是在 App 裡。
- `saveFiles()`／`appShareFiles()`：App 裡沒有「下載」，改成先寫進 App 暫存資料夾（`@capacitor/filesystem`），再打開分享面板（`@capacitor/share`）；大檔案用 3MB 一段寫入。網頁版行為不變。備份、小卡、出售貼文、貼圖、相簿存圖都改用它。
- App 裡不註冊 Service Worker、不檢查網頁版更新。

- App 外殼（2026-09-29）：`package.json`、`capacitor.config.json`（`appId` 是使用者選的 `com.shiunxun.wawacloset`（2026-09-29 確認），**上架後不能改**）、`scripts/build-www.js`（複製網站到 `www/`）、`android/`、`ios/`（Capacitor 8，iOS 用 Swift Package Manager）。
- 圖示、啟動畫面：原始圖在 `assets/`（由 `icons/brand/wawa-icon.svg` 的角色畫出來；iOS 圖示不能透明、不能自己切圓角），用 `npx @capacitor/assets generate` 產生。**這個工具也會在 `icons/` 產生 `.webp`，要刪掉**，網站的圖示不要動。
- iOS `Info.plist`：相機、相簿、存到相簿的中文說明；只能直立；`ITSAppUsesNonExemptEncryption=false`。Android 只能直立。
- 使用者試裝步驟：`docs/App打包教學.md`。
- 網頁改了之後，App 要 `npm run sync` 才會拿到新版（App 不會自己去網站抓新版）。
- 通知（App）：`@capacitor/local-notifications`。`notifyList(later)` 列出「`today()` 這一天」要提醒的事；App 把 `TODAY_AT` 暫時設成未來每一天，預先排好接下來 30 天、每天早上 9 點的通知（最多 60 個，iPhone 上限 64）。排過、時間已過的記進 `notified`，不會重複。`save()` 之後 4 秒會重新排。網頁版照舊：打開時才跳。Android 小圖示 `res/drawable/ic_stat_wawa.xml`；拿掉了外掛帶進來的 `SCHEDULE_EXACT_ALARM`（Google Play 限制）。
