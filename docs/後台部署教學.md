# 哇娃衣櫃 AI 後台部署教學（Cloudflare Workers，免費）

做完之後，網頁和 App 的 AI 功能都會先連到**你的後台**，再由後台帶著密鑰去問 AI。
使用者看不到 API 地址和密鑰，也不需要自己設定任何東西。

> ⚠️ 密鑰只填在 Cloudflare 的設定頁，**不要**貼進程式碼、不要傳給任何人、不要放上 GitHub。

整個過程大約 15 分鐘，全部用瀏覽器完成，不用安裝任何東西。
（Cloudflare 的畫面偶爾會改名字或換位置，找不到按鈕時用頁面上的搜尋，或截圖給我看。）

---

## 1. 註冊 Cloudflare

1. 到 <https://dash.cloudflare.com/sign-up> 用 email 註冊，收信點驗證。
2. 免費方案就夠用：每天 10 萬次請求。

## 2. 建立 Worker

1. 左邊選單點 **Workers & Pages**（有時在 **Compute** 底下）。
2. 按 **Create**（建立）→ 選 **Start with Hello World!**。
3. 名字可以取 `doll-ai`，按 **Deploy**。
4. 部署完會看到一個網址，長得像 `https://doll-ai.你的帳號.workers.dev`，**記下來**。

## 3. 貼上後台程式

1. 在這個 Worker 的頁面按右上角 **Edit code**。
2. 左邊的 `worker.js`（或 `index.js`）裡面的內容**全部刪掉**。
3. 打開 GitHub 上這個專案的 `server/worker.js`，按 **Raw** 或複製按鈕，把全部內容貼進去。
4. 按右上角 **Deploy**。

## 4. 填設定（最重要）

回到 Worker 的頁面 → **Settings** → **Variables and Secrets** → **Add**。一個一個加：

| 名稱 | 類型 | 要填什麼 |
|---|---|---|
| `API_BASE` | Text | 你的 API 地址，填到 `/v1` 為止，例如 `https://api.xxx.com/v1`（只填網域 `https://api.xxx.com` 的話，後台會自動補上 `/v1`） |
| `API_KEY` | **Secret** | 你的 API 密鑰（**一定要選 Secret**，存了之後連你自己都看不到，這是正常的） |
| `MODEL_TEXT` | Text | 分析用的模型。名稱請從中轉站的模型清單**整段複製**，例如 Gemini 3 Flash 通常叫 `gemini-3-flash-preview`，有的中轉站前面還要加 `google/`；名稱不對會出現「AI 服務設定有誤（模型或格式）」 |
| `MODEL_IMAGE` | Text | **現在不用填。** App 從 2026.10.01-64 起改用「AI 自動去背」（在手機上剪原照片），不再請 AI 出圖。下面四個 `IMAGE_*` 也一樣不用填 |
| `IMAGE_API_BASE` | Text | 選填：出圖模型在**另一個中轉站**才要加，填那邊的地址（到 `/v1`） |
| `IMAGE_API_KEY` | **Secret** | 選填：另一個中轉站的密鑰 |
| `IMAGE_API_STYLE` | Text | 選填：`chat`（對話格式）、`task`（ToAPIs）、`studio`（1route Studio）。地址裡有 toapis／1route 會自動判斷，通常不用填 |
| `IMAGE_QUALITY` | Text | 選填：GPT Image 的品質 `low`／`medium`／`high` |
| `ALLOWED_ORIGINS` | Text | `https://shiun-wq.github.io,capacitor://localhost,https://localhost` |

- `ALLOWED_ORIGINS` 規定哪些網址可以用你的後台：GitHub Pages 的網頁，加上之後的 App（iPhone 是 `capacitor://localhost`，Android 是 `https://localhost`）。
- 之後如果網站搬到別的網址，要記得把新網址加進來（逗號分隔、不要有空格也沒關係）。

每加完一個都按 **Save / Deploy**。

## 5. 防止被刷爆帳單（強烈建議）

不做這步也能用，但任何人拿到網址就能一直打，錢是從你的 API 額度扣的。

1. 左邊選單 **Storage & Databases** → **KV** → **Create**（建立命名空間），名字取 `doll-quota`。
2. 回到 Worker → **Settings** → **Bindings** → **Add** → 選 **KV namespace**。
   - Variable name 填 `QUOTA`（要一模一樣，大寫）
   - KV namespace 選剛剛的 `doll-quota`
3. 按 **Deploy**。

綁好之後預設的限制是：

| 名稱（選填，Text） | 預設 | 意思 |
|---|---|---|
| `DAILY_LIMIT` | 30 | 每台裝置每天最多用幾次 AI |
| `GLOBAL_DAILY_LIMIT` | 300 | 所有人加起來每天最多幾次（最後一道保險） |

想改數字就在 Variables 再加這兩個。KV 免費版每天可以寫 1000 次，朋友試用完全夠。

## 6. 檢查

用瀏覽器打開：

```
https://doll-ai.你的帳號.workers.dev/health
```

看到類似這樣就是成功：

```json
{"ok":true,"api":true,"key":true,"text":true,"image":true,"imageApi":false,"imageKey":false,"limit":true,"origins":true}
```

- `ok` 是 `false` → 前三個（`API_BASE`、`API_KEY`、`MODEL_TEXT`）有漏填。
- 有用另一個出圖中轉站的話，`imageApi` 和 `imageKey` 要是 `true`。
- `limit` 是 `false` → 第 5 步的 KV 沒綁好（能用，但沒有次數限制）。

## 7. 把網址給我

把 `https://doll-ai.你的帳號.workers.dev` 這個網址傳給我（**只要網址，不要密鑰**），我幫你寫進網頁裡，之後所有人打開網頁就會自動走你的後台。

在那之前你可以自己先試：

1. 網頁 → 右上角設定 → **連點「設定」這兩個字 7 下** → 打開開發者模式。
2. 「後台網址」填你的 workers.dev 網址，選「走後台」。
3. 按「連不上？跑一次診斷」，會告訴你哪裡沒設好。

## 常見問題

**Q：出現「這個網址沒有被允許使用 AI」**
`ALLOWED_ORIGINS` 沒包含你現在用的網址。診斷頁會顯示要加的網址。

**Q：出現「AI 服務設定有誤（密鑰）」**
`API_KEY` 填錯，或 API 那邊的額度用完了。重新 Add 一次 `API_KEY` 蓋過去。

**Q：出現「AI 服務設定有誤（模型或格式）」**
`MODEL_TEXT` 或 `MODEL_IMAGE` 名稱打錯。
想看詳細錯誤：暫時加一個 `DEBUG` = `1`，查完記得刪掉（不然使用者會看到上游的錯誤內容）。

**Q：開發者模式要怎麼關？**
設定裡「開發者模式」旁邊的「關閉」。一般使用者不會看到任何 API 相關的設定。

**Q：要錢嗎？**
Cloudflare Workers 和 KV 的免費額度對試用階段綽綽有餘。會花錢的只有你原本的 AI API 用量。
